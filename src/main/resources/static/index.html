What does API-RateLimiter do?

API-RateLimiter acts as a protective layer between your application and a target REST API. It counts incoming requests and allows or blocks them according to the configured rate limit.

Client → API-RateLimiter → Rate limit check → Target API
Allowed → forward request Exceeded → HTTP 429
1 Configure API
2 Create protected endpoint
3 Send request
4 Rate limit check
5 Forward or return 429

API endpoint ≠ website URL

API-RateLimiter is designed for REST/API endpoints. Normal website URLs such as youtube.com are web pages, not necessarily APIs, and may not work correctly through an API proxy.

API endpoint vs Website URL

An API endpoint is designed to receive programmatic HTTP requests and return data, commonly JSON. A website URL is designed to serve a web page and may depend on browser features, cookies, JavaScript and other resources.

  • ✓ https://api.example.com/users API
  • ✓ http://localhost:8081/api/users Local API
  • ✕ https://youtube.com Website
API-RateLimiter Built for protecting REST APIs, not general websites.
